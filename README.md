# Another citadel calculator

Total Battle citadel attack planner (Elven 10–30, Cursed 20–25): battle simulation calibrated on real reports, zero-loss or community-layout plans, battle log and comparison with the tb-citadel-calculator plan.

This repository holds only the published page (`index.html`, minified). Open it at the GitHub Pages URL of this repository or download the file and open it in a browser: it works offline, nothing is sent anywhere.

Units, guard cards and formulas come from community sources (Joe's Journal vol. 13, totalcalculator.org, tb-citadel-calculator, TBCounter, Kaiculator); nothing here is official.
